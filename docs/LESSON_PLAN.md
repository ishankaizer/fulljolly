# Word Nest lesson plan

Generated from `src/data/course.ts`. Do not edit by hand: change the data and run `npm run plan`.

Children move along the course in order. Every word only uses sounds taught before it (checked by `npm run check:course`),
so a child can always sound it out. Suggested pace: one lesson a day, ten to fifteen minutes, with a Games session
every few lessons to revisit.

## How each kind of lesson runs

| Lesson | What the child does |
|---|---|
| Sound | Hear the sound with a keyword, trace the letters, pick the letter that makes a sound (x3), blend a card of words by touching a dot under each sound, build two words from tiles, match two pictures, find two words by ear |
| Three-letter family | Meet the ending, trace the vowel, slide to blend every word, build the first sound of four words, match four pictures |
| Four-letter words | Hear two letters that keep both their sounds, blend a card of words, build three from tiles, match two pictures, find two words by ear |
| Tricky words | See and hear each word, find it by ear, build short sentences that use it |
| Sentences | Read four sentences, match three to pictures, build all four in order |
